# Codebuch für Anne Will Übung

untersucht wird ein Netzwerk der Gäste von Anne Will

### Nodelist
id = Initialen  
name = voller Name (Mensch oder Partei)  
sex	= 1 = weiblich, 2 = männlich, 3 = divers  
party	= Parteizugehörigkeit (Abkürzung der Partei)  
sector =	Arbeitsbereich z.B Politik  
type	= 1 = Person, 2 = Organisation  
country =	Land

### Edgelist
from =	Sendeknoten id (Gast)  
to	= Folge oder Parteimitgliedschaft  
relationship	= 1 = Sendungsgast, 2 = Parteimitgliedschaft
